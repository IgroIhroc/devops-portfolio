# DevOps Portfolio — IgroIhroc

Я вивчаю DevOps і збираю тут практичні роботи курсу. Моя професійна мета — навчитися будувати відтворювані середовища та автоматизувати шлях від зміни в Git до розгортання й моніторингу сервісу.

## Технології

| Уже застосовую в портфоліо | Планую вивчити |
| --- | --- |
| Git, GitHub, гілки й pull requests | Docker і Compose, GitHub Actions, Terraform, Kubernetes, Prometheus і Grafana |

## План на рік

| Період | Практичний результат |
| --- | --- |
| 1–3 місяці | Закріпити Git і Linux, запустити застосунок та базу даних через Compose. |
| 4–6 місяців | Побудувати CI з тестами, збиранням і публікацією образу. |
| 7–9 місяців | Описати інфраструктуру в Terraform і розгорнути застосунок у Kubernetes. |
| 10–12 місяців | Додати моніторинг, підготувати процедуру відновлення й оформити фінальний проєкт. |
